Expose the last lock action's user ID and PIN slot owners for Home Assistant automations.

## Highlights
- Add `user_id` and `code_users` attributes to each lock's Last Action sensor. `code_users` maps PIN slot numbers to user IDs; passcode digits are never exposed.
- Fire `nest_yale_lock_action` for newly timestamped completed actions, including repeated actions by the same user. Event data contains `device_id`, `method`, `user_id`, and `timestamp`.
- Keep action user IDs per lock and separate from the account ID used for Nest API calls.

## Beta testing
- In HACS, enable pre-releases for this repository and install `2026.09.25b1`, then restart Home Assistant.
- Check the Last Action sensor attributes and listen for `nest_yale_lock_action` while testing a keypad unlock.
- The first observed action after startup establishes the event baseline; the event fires for subsequent newly timestamped actions.
