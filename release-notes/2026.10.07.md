Stable release: fix state refresh failures on Home Assistant 2026.10 (#46).

## Highlights
- Replace removed `FieldDescriptor.label` checks with `is_repeated` in both trait merge helpers and map detection. This fixes the missing `label` error with protobuf 7.x during state updates.
- Update the local PyJWT requirement to `>=2.15.1,<3.0` (#44).
- Update the development-only googleapis-common-protos dependency to `1.75.5` (#45). This development package requires protobuf `>=6.33.5`; the integration manifest retains `protobuf>=6.32.0,<8.0` and uses Home Assistant's PyJWT.

## Validation
- All 19 existing unit tests pass with protobuf `6.32.0`, `6.33.5`, and `7.36.0`.
- Additional local checks cover both trait merge helpers, repeated scalar and message fields, scalar and message maps, and preservation of unchanged fields. These reproduce the failure before the fix and pass afterward.
- The updated development dependencies pass the test suite with protobuf `6.33.5` and `7.36.0`; PyJWT `2.15.1` passes a token-decoding smoke test.
- HACS, Hassfest, and Prettier checks passed for PRs #44, #45, and #46.
- The PR contributor reports the protobuf fix working on their Home Assistant installation; maintainer validation was local, without a live lock test.

## Breaking changes
- None. Includes the features from `2026.09.28`.

## Installation
- Update Google Nest x Yale to `2026.10.07` in HACS; pre-releases do not need to be enabled.
- Restart Home Assistant after updating.
