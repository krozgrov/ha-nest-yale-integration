Stable release: identify who performed each lock action (#38).

## Highlights
- Last Action sensor exposes `user_id`, `agent_id`, and `code_users` (PIN slot number to user ID map, no passcode digits).
- Keypad actions report the guest slot user; app, remote, and voice actions report the household member.
- New `nest_yale_lock_action` event with `device_id`, `method`, `user_id`, `agent_id`, and `timestamp`, fired for each newly timestamped completed action (including repeat unlocks by the same user).
- Dependency update: PyJWT `>=2.15.0,<3.0`.

## Validation
- Beta-tested on real locks across `2026.09.25b1` and `2026.09.27b1` (keypad, app, and voice actions).

## Breaking changes
- None. Includes everything from `2026.09.25b1` and `2026.09.27b1`.
