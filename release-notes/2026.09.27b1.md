Identify the user behind app and remote lock actions when Nest reports one (#38).

## Highlights
- Read the lock actor's `agent` field alongside `originator`. When a remote/app action has no originator but the agent is a user (`USER_…`), `user_id` now reports that user.
- Add `agent_id` to the Last Action sensor attributes and to `nest_yale_lock_action` event data, so non-user agents are visible too.
- Log the raw actor at debug level for remote actions that still have no user, to help map what Nest sends.

## Beta testing
- In HACS, enable pre-releases for this repository and install `2026.09.27b1`, then restart Home Assistant.
- Unlock from the Nest/Google Home app as different household members and check `user_id` / `agent_id` on the Last Action sensor or the `nest_yale_lock_action` event.
- If `user_id` stays `null`, enable debug logging for `custom_components.nest_yale_lock` and share the `Remote action on … has no user originator` log line (redact IDs as needed).
